# Скилл: транскрипция записи

**Задача.** Получить проверяемый текст с таймкодами и передать его в общий разбор встречи.
**Когда.** Есть запись аудио или видео. Готовая текстовая стенограмма сразу идёт в [разбор встречи](meeting-digest.md).

## Подготовка среды

**Установку отделяй от работы с записью.** Подготовь локальную среду распознавания, например с faster-whisper. Зависимости и выбранная модель скачиваются заранее; модель достаточно загрузить один раз для этой среды. До загрузки строгую работу без сети не обещай. При смене модели или среды подготовка может понадобиться снова.

Примеры команд общего вида, заполнители замени своими путями:

```sh
python3 -m venv "<каталог-среды>"
"<каталог-среды>/bin/python" -m pip install faster-whisper
```

Загрузи модель в локальный каталог средствами выбранного распознавателя. Проверь распознавание короткой тестовой записи без сети и отключи автоматическую загрузку недостающих файлов. **После подготовки работа с записью идёт локально без сети.** Если чего-то не хватает, остановись и вернись к подготовке; не подменяй её отправкой записи во внешний сервис.

Этот файл описывает метод; готового скрипта распознавания в наборе нет.

## Протокол

1. Определи исходную запись, язык и доступный список участников. Сохрани исходник без изменений. Если запись началась позже встречи, отметь это: таймкод файла не равен времени начала встречи.
2. Проверь звук и выдели аудиодорожку. Длинную запись раздели на части, которые среда успевает обработать за один запуск. Для каждой части запиши начало в исходном файле и длительность. Общий вид команды нарезки:

   ```sh
   ffmpeg -i "<запись>" -ss "<начало>" -t "<длительность>" "<часть>.wav"
   ```

3. В рабочем состоянии сохраняй список частей: файл, начало, длительность, статус и путь к результату. Отмечай часть завершённой только после сохранения и проверки результата. При обрыве продолжай с первой незавершённой части, сохраняя уже принятые результаты.
4. Распознай каждую часть с таймкодами. **Глобальный таймкод = таймкод внутри части + её начало в исходной записи.** При последовательной нарезке без перекрытий начало равно сумме длительностей предыдущих частей. При перекрытиях бери фактическое начало, иначе сдвиг накопит ошибку. Удали дубли на стыках и проверь, что нет пропущенных фрагментов.
5. Прослушай спорные места. **Имена и ключевые цитаты сверь с записью**, написание имён проверь по разрешённому справочнику. Неясный голос пометь как неопределённый. Автоматическая разметка спикеров сама по себе не доказывает, кто говорил.
6. Передай весь текст в [meeting-digest.md](meeting-digest.md). Протокол разбора общий для локальной записи, готовой стенограммы и другого источника; краткая выжимка распознавателя его не заменяет.

## Результат и границы

В систему переноси **разобранный итог**, решения и проверенные действия по правилам разбора встречи. Сырую стенограмму, части аудио и состояние обработки держи отдельно от постоянных заметок, с согласованным сроком хранения и доступом для сверки. Не удаляй исходник, пока остаются спорные цитаты или поручения.

В результате укажи покрытый отрезок записи, пропуски и места с сомнениями. **Плохо распознанный фрагмент не становится фактом о человеке или поручением.**

## Происхождение и границы

Обобщённый метод из практики работы руководителя с агентом: проверка посылки,
независимые линзы, сведение разногласий и честная цена рекомендации. Текст подготовлен
для публичного стартера; личные настройки, переписки, реальные эпизоды и код не входят.

Это инструкция, а не исполнитель проверок и не набор готовых интеграций.
Пять линз не означают обязательные пять процессов на любую задачу.
Независимость требует отдельных проверяющих; если их нет, ограничение указывается явно.
Нормы и контракты внешних систем проверяются заново для конкретного решения.
Метод помогает подготовить выбор владельца, но не даёт разрешения на внешнюю запись.
